# py_teleparse

`py_teleparse` — асинхронный Telegram-бот для получения последних сообщений из публичного канала и генерации краткой сводки через LLM.

Проект использует два Telegram-клиента:

- **Bot API клиент** — принимает команды, кнопки и отвечает пользователю;
- **UserBot клиент** — читает историю канала через пользовательскую сессию Telegram.

Дополнительно проект использует Redis для хранения FSM-контекста и распределённых локов, а LangChain — как слой интеграции с LLM.

## Что подтверждено кодом на момент аудита

- приложение запускается из `src/main.py` и работает без HTTP/webhook;
- пользовательский сценарий построен вокруг inline-кнопок и FSM в Redis;
- бот умеет получать `username` публичного канала, забирать последние `N` сообщений и отдавать одну итоговую сводку;
- суммаризация сейчас реализована **в один LLM-вызов**, без чанкинга, группировки по темам и отдельного budget-контроля по токенам;
- Docker-артефакты в репозитории есть, но их текущая конфигурация **не полностью синхронизирована** с загрузчиком настроек приложения и требует отдельной валидации перед production-использованием.

## Ключевые ограничения

- поддерживаются только каналы, которые может открыть пользовательская Telegram-сессия;
- в LLM попадает только поле `message` из Telegram-сообщения;
- media-only сообщения могут попасть в пайплайн как пустой текст;
- поле конфигурации `LLM__TOKENS` сейчас объявлено, но кодом не используется;
- поле `LLM__API_URL` объявлено в настройках, но в текущем `LLMProvider` не передаётся в модель.

## Быстрый старт для локальной разработки

1. Установите Python **3.13** и `uv`.
2. Поднимите Redis локально или через Docker:
   - рекомендуемый вариант для разработки: `docker compose up -d cache`
3. Создайте файл `src/.secrets/.env`.
4. Установите зависимости:
   - `uv sync`
5. Запустите приложение из корня репозитория:
   - `uv run python src/main.py`
6. На первом запуске авторизуйте **userbot** в интерактивном терминале, если сессия ещё не создана.

Подробный onboarding находится в `docs/onboarding.md`.
